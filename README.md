# Fix-Request-Desktop-Website

Remember when the 'Request Desktop Website' button used to actually do something? That was back when websites would try to detect whether you were on a mobile device or desktop, rather than just looking at the width of your screen. Despite most websites now using responsive design, Safari's 'Request Desktop Website' button still tries to tell the website you're on desktop rather than just spoofing the viewport to a wider resolution. With this tool, you can finally use that one feature that wasn't properly built into the mobile version of your favorite website.

1. Load the script using a userscript manager, like Tampermonkey or Userscript
2. Hit the plain-old 'Request Desktop Website' button
3. Enjoy!
